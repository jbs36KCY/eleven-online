# ELEVEN 온라인 대전 프로토타입

기존 v23 AI 대전에 실시간 서버 기반 2인 대전을 추가한 개발용 프로젝트입니다. 실제 인터넷에 배포된 서비스가 아닙니다.

## 포함 기능
- AI 대전: 기존 HTML 게임 유지
- 온라인 대전: 6자리 방 코드 생성, 친구 참가, 방장 파란 팀 / 참가자 빨간 팀
- 서버가 공·22명 선수·점수·시계를 계산하고 약 20Hz로 상태 전달
- 양쪽 선수 이동·달리기(E)·패스(S)·스루(W)·크로스(A)·슛(D), Z/Q/F/C 조합 슛
- 수비 S 선수 변경, Shift 치달, Q+1/2/3/4 침투
- 패스 수신 AI 추적과 소유 후 조작 전환
- 1/3/5/9분 경기, 전후반, 양쪽의 ‘후반 준비’ 클릭 후 후반 시작
- 경기 종료 시 득점·슛·선방·패스·점유율
- 연결 해제 시 경기 종료, 대기 방 15분 만료

## 먼저 내 PC에서 확인
Node.js 20 이상이 필요합니다. 압축을 풀고 package.json이 있는 폴더에서:

```sh
npm install
npm test
npm start
```

브라우저로 http://localhost:3000 접속합니다. 다른 브라우저 창도 같은 주소를 엽니다. 첫 창에서 온라인 대전 → 방 만들기, 두 번째 창에서 코드 입력 → 참가합니다. 두 명이 입장하면 자동 시작합니다. 방장이 선택한 경기 시간이 적용됩니다.

로컬 주소 localhost는 친구에게 공유해도 접속되지 않습니다. 아래처럼 배포한 HTTPS 주소를 공유해야 합니다.

## GitHub 연동 배포 예: Render
1. GitHub에서 새 저장소를 생성합니다.
2. 이 폴더 안 파일들을 저장소 최상위에 업로드합니다. node_modules는 올리지 마세요.
3. Render에서 GitHub 저장소를 연결해 Node Web Service를 생성합니다. Static Site가 아닙니다.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. 배포가 끝난 HTTPS 주소를 둘 다 열고 온라인 대전으로 접속합니다.

render.yaml도 포함했습니다. 호스팅의 요금, WebSocket 지원, 절전 정책은 계정 생성 시 확인하세요. 저장소만 업로드하거나 GitHub Pages만 켜서는 실시간 서버가 동작하지 않습니다. 계정 로그인·결제·배포 승인 등은 사용자가 직접 진행해야 합니다.

## 조작과 제약
- 두 팀 모두 화면 기준 방향키로 조작합니다. 파란 팀은 오른쪽 골문, 빨간 팀은 왼쪽 골문을 공격합니다. 후반 진영 교대는 하지 않습니다.
- 패스/슛 버튼을 누른 시간에 따라 세기가 결정됩니다.
- 온라인은 서버 시뮬레이션이므로 창을 벗어나도 경기가 일시정지되지 않습니다.
- 온라인 경기 중 경기 시간 변경·새 경기·일시정지 설정은 적용하지 않습니다. 다시 하려면 새로고침하고 새 방을 만드세요.
- 결과 표는 우리 팀=파란 팀, 상대 팀=빨간 팀 기준입니다.
- AI와 온라인은 다른 실행 경로입니다. 기존 AI 전용 키의 모든 세부 동작이 온라인과 완전히 같지는 않습니다. 온라인 슬라이딩·골키퍼 수동 돌진·원터치 입력 예약은 미구현입니다.
- 패스 통계는 선수의 패스 시도와 다음 포구가 같은 팀인지로 집계합니다. 골키퍼 배급은 제외합니다. 유효슛·xG·정밀 전술 분석은 미구현입니다.
- 네트워크 보간/롤백 미구현: 지연 시 움직임이 끊겨 보일 수 있습니다.
- 서버 메모리에 방을 저장하므로 서버 재시작 시 방이 사라집니다. 단일 서버 인스턴스 전용입니다.
- 회원·랭킹·재접속·관전·음성채팅·안티치트·대규모 서비스 운영은 포함하지 않습니다.
- 시작 시간은 브라우저가 아닌 서버가 계산합니다. 부하가 높으면 물리 시뮬레이션이 느려질 수 있습니다.
- 호스팅 환경의 실제 WebSocket 연결은 사용자가 배포 후 검증해야 합니다.

## 검증 범위
코드 문법과 서버 경기 엔진의 독립 시뮬레이션 검사를 제공합니다. 여기서 실제 서버를 열거나 외부 호스팅에 배포하지 않았고, 브라우저 두 대의 종단간 플레이 검증은 하지 않았습니다. 테스트 통과가 인터넷 대전의 완성도를 보증하지는 않습니다.

## 파일
- server.js: HTTP/WebSocket 서버, 방 생성/참가, 입력 검증, 주기적 경기 상태 전송
- engine.js / engine-source.js: 기존 게임을 기반으로 한 서버 시뮬레이션
- public/index.html: AI 게임 및 온라인 클라이언트
- test.js: 독립 엔진 시뮬레이션 테스트
- render.yaml: 배포 설정 예시
